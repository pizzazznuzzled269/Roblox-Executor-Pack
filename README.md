## FAQ

### What is XCutors?

XCutors is a curated collection of popular Windows Roblox script executors bundled with a universal loader. It packages Volt, Synapse Z, Potassium, Wave, and xcutorsLoader into a single convenient download for users who work with multiple Lua execution environments.

### What are the system requirements?

XCutors requires a Windows 10 or Windows 11 PC, a stable internet connection, and the latest version of Roblox installed. A minimum of 4 GB RAM is recommended for smooth operation, especially when running multiple executor instances.

### How do I update the executors?

XCutors includes a built-in auto-update mechanism. When you launch xcutorsLoader, it will automatically check for new versions of each executor and prompt you to download and install any available updates. You can also manually check via the Settings menu.

### Can I use multiple executors at the same time?

Yes. The universal loader supports multi-instance operation, allowing you to run different executors simultaneously or use the same executor across multiple Roblox sessions. Note that system performance may vary depending on your hardware.

### Where can I find scripts to use?

XCutors includes a built-in script hub accessible from the loader interface. You can also find community-shared scripts on popular Lua scripting forums and repositories. Always verify scripts from untrusted sources before execution.

### Is XCutors free to use?

The universal loader (xcutorsLoader) is free and open-source. Individual executors included in the bundle may have their own licensing terms — some are free while others may require a license key or subscription. Check each executor's documentation for details.

### The application is flagged by my anticomponent. Is it safe?

Script executors commonly trigger false positives from anticomponent software due to the nature of their process interaction. We recommend adding the XCutors folder to your anticomponent exclusion list. Always download XCutors exclusively from this official repository to ensure authenticity.

### Which executor is best for beginners?

For beginners, we recommend starting with Wave or the built-in xcutorsLoader default executor. Both offer user-friendly interfaces with drag-and-drop script loading, clear execution feedback, and access to the integrated script hub.

### How do I report a bug or request a feature?

Please open an Issue on this GitHub repository using the appropriate template (Bug Report or Feature Request). Include detailed steps to reproduce any bugs, your operating system version, and the executor you were using at the time.

### Does XCutors work on macOS or Linux?

No. XCutors is designed exclusively for Windows desktop environments. The executors in this collection rely on Windows-specific APIs and are not compatible with macOS or Linux systems.
